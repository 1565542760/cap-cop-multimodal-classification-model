## Release blockers before claiming full exact reproduction

1. Decide and lock the scientifically correct internal patient mapping after the
   historical bridge discrepancy; do not silently retain the historical mismatched
   result.
2. Decide how the historical C identity audit will be described in the paper: retain the
   existing lock as an explicitly audited legacy result, or authorize a separate
   corrected-canonical analysis. The public raw-DICOM-to-SP6/C replay is now numerically
   verified under the locked V3.8 input contract; this does not itself authorize changing
   the manuscript result.
3. Keep D labelled exploratory and document the historical batch-size contract and
   external source-version boundary; the current batch-size-2 replay matches the
   locked prediction probabilities to numerical tolerance.
4. Complete data-sharing, pixel de-identification and privacy approval before any
   patient-level data or weights are published.
